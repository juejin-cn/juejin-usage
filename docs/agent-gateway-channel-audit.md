# 本机代理渠道实测与转发模式复核

检查日期：2026-11-07（Asia/Shanghai）。本次仅覆盖本机已启用的 4 个渠道、35 个开放模型；不代表其他账户、未登录渠道或已排除模型的可用性。

逐项证据见 [脱敏检查结果](./agent-gateway-channel-audit-results.json)，包含首轮 47 项和修复后 15 项检查，已移除本机渠道 UUID。修复后 14 项通过，1 项 CLI 工具检查未通过。

## 验证方法

模型目录可见只作为清单依据。每个开放模型通过 Messages 流式入口实际生成一次，要求精确回复随机校验串、有可见文本并收到协议终结事件。首轮共执行 47 项检查：35 次模型推理、3 个代表模型各 3 个附加协议入口、3 次真实 Claude Code Read 工具闭环。

代表模型为 Codex 的 `gpt-6.1-sol`、WorkBuddy 的 `hy4free`、Antigravity 的 `gemini-2.5-flash`。代表模型覆盖 Chat、Messages、Responses、Gemini 四种流式入口。工具验证在临时目录创建随机文件，只允许 Read 读取该文件，检查模型调用、工具结果和最终答案；不向其他渠道发送用户项目内容。

不验证所有模型的全部工具、图片、长上下文或完整 IDE 工作流；不能据此声明这些能力全部兼容。发生 429 不绕过限制、不更换账户或清空健康状态。探测可能消耗账户额度。

## 已定位并修复的网关问题

三个成功渠道的 Gemini 入口首轮均返回 502。网关历史记录显示 `UPSTREAM_EMPTY_STREAM`，发生在发送给客户端之前。转换器已生成合法 Gemini `candidates` 事件，但响应准备阶段的 SSE 检测器仅识别其他三种协议，未识别 Gemini 文本、函数调用与结束原因。

[response.ts](../packages/core/src/agent-router/response.ts) 已增加 Gemini 候选内容、函数调用、内嵌媒体和 `finishReason` 检测；真正空的候选流仍然拒绝，嵌入式错误仍按错误处理。新增回归用例在修复前复现 `UPSTREAM_EMPTY_STREAM`，修复后与 Gemini／路由相关测试共 27 项通过。

## 转发模式复核结论

参考实现的核心做法是将客户端接管、协议转换、供应商账户传输分层，并按实际请求行为记录能力，而非依赖统一的“已接入”标志。本项目已有这三层，下一步应补齐诊断和能力数据：

1. **按账户、模型、入口协议记录检查结果。** 目录存在、凭据就绪、文本成功、工具闭环分别记录，附检查时间、阶段和失败码；通用 400/404 不应抹掉本机适配器产生错误的来源。
2. **模型清单与当前账户实际目录核对。** 保存的开放模型可能过期。提供差异结果供用户审阅，不能自动删除模型、修改排除列表或切换用户选中的模型。
3. **流完整性单独验证。** HTTP 200、首个有效内容与正常终结是不同阶段；短输出预算导致仅有推理或达到长度限制时，不能误判为文本生成成功。
4. **保留提交边界。** 只在尚未向客户端提交内容时有限重试；已提交后断流不能换渠道重放。带签名或密文历史应绑定原账户和模型。
5. **传输能力独立于协议能力。** 对订阅 Responses 的长流，参考实现优先使用上游 WebSocket，并仅在握手失败或提交前断开时回退 HTTP。本项目当前仍使用 HTTP/SSE；本轮短请求通过不证明超过两分钟的长流稳定，也不代表已支持 WebSocket。
6. **探测可以取消且有上限。** 每个渠道串行、渠道间有限并发，设置超时和清理；仅发送隔离的校验提示词，不记录凭据、原始提示词、工具文件内容或供应商原始错误体。

本轮不因目录标签推断专用模型是否能聊天，所有开放模型都实际发起了基础推理；不因某一个模型通过就把整个渠道标记为完全兼容。签名恢复、供应商内置工具、JSON 聚合和长流仍需各自验收。

## 复现

[check-agent-gateway.mjs](../scripts/check-agent-gateway.mjs) 读取本机网关配置及已接管的 Claude 连接配置，凭据仅留在内存。必须显式传入 `--live` 才执行真实推理，不改用户模型或渠道配置。输出只包含检查状态、模型标识、错误码和耗时，建议保存到仓库外。

```sh
node scripts/check-agent-gateway.mjs --live --output /tmp/gateway-audit.json
node scripts/check-agent-gateway.mjs --live --model gpt-6.1-sol --model hy4free --model gemini-2.5-flash --output /tmp/gateway-recheck.json
```

`--model` 可重复指定，用于选择已配置的模型名称。未全部通过时进程退出码为 1。网关需已运行，本机需安装 Claude CLI；每个代表模型的 CLI 验证最多 65 秒，之后终止并清理临时文件。
