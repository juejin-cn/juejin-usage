# Trae 国际版用量与额度（Tauri）

Tauri 桌面端及本地 CLI 面板现在可复用 Trae 国际版已有登录态，读取官网 Usage Events 和账号金额额度。它们不需要 SQLCipher 会话数据库密钥，不需要关闭 SIP、修改应用签名、读取进程内存或安装 `trae-db-recovery`。

## 使用方式

1. 在 Trae 国际版中登录账号，再打开用量面板执行同步。
2. 订阅区域可显示「Trae 国际版」；设置中的订阅渠道开关可控制显示。卡片刷新读取的是额度，不是历史用量；历史用量使用面板同步入口。
3. 默认读取 macOS `~/Library/Application Support/Trae/User/globalStorage/storage.json`，也识别 `TRAE` 和 `TRAE SOLO` 目录。Windows 从 `%APPDATA%`、Linux 从 `$XDG_CONFIG_HOME` 或 `~/.config` 查找相同目录。自定义安装可通过 `TRAE_HOME` 指定应用数据根目录。

只读取 `iCubeAuthInfo://icube.cloudide` 登录记录，支持 JSON 和带完整性校验的 byteCrypto 封装。登录凭据仅在内存中用于访问固定的 Trae 官方地址，不写入本项目队列、日志或订阅响应；不保存提示词和原始会话 ID。登录过期时，在 Trae 中重新登录，本项目不替 Trae 刷新或改写凭据。

默认使用国际版 SG 服务；按 Trae 客户端的地区规则，优先读取 `userRegion._aiRegion`，其次读取 `account.uidRegion`、`aiRegion`，兼容旧的 `region`；明确标记 US 时使用 US 服务。不会把凭据转发到自定义地址或跟随重定向。未知登录格式和地区会显示读取失败。还未启用官网采集时，原有手动配置密钥的数据库采集路径继续有效；本项目不会自动获取数据库密钥。

## 统计范围与限制

- **官网数据属于整个账号的所有设备。** 在本地面板、Tauri 托盘及本地统计中展示，暂不上报掘金和排行榜，以免每台设备重复上传同一份账号数据。
- 用量按官网 `usage_time` 放入半小时桶，并使用面板已有时区设置汇总日期。不能据此还原跨日会话的逐次请求时间、项目和请求数：项目为 unknown，请求数标为不完整。
- 输入 Token 沿用现有 Trae 采集器的口径：输入包含缓存读取，展示的非缓存输入为 `input_token - cache_read_token`，总量不再额外加一次缓存读取。这个官网内部字段口径仍需要真实账号与官网对照；**非零缓存写入及缓存读取大于输入的记录暂不采纳，整批保留旧快照并提示**，避免未经验证的重复累计。
- 费用直接展示官网 `dollar_float`（包括 0），不按公开模型价格重新推算。
- 正常后台采集最短间隔 60 秒；手动同步可立即重试。完整翻页成功后替换窗口内旧快照，重复同步不会累加，更新、移位或删除的桶会撤回。分页失败、格式变化、限流及断网保留上次数据。
- 官网采集启用后不再同时解析国际版数据库。首次成功切换时，窗口内旧国际版数据库桶被撤回，国内版数据库采集仍独立保留。账号切换后，下一次成功同步会替换先前账号的官网历史；请求失败时保留原有本地历史，不将其混入新账号额度卡片。
- 卡片套餐由实际 `product_type` 决定；基础、奖励和额外额度是额度类别，不是套餐等级。只支持返回金额限额的套餐，不把旧计次套餐换算成美元。暂不提供国内版官网采集和订阅卡片。
- 历史窗口以官网实际返回为准，服务端可能限制可查询历史。服务端未提供的历史不会被补造。

## 验证状态与接口依据

本次覆盖了合成登录记录、加密登录封装、SG/US 地址选择、分页、更新和撤回、失败保留、账号切换、零费用、上传隔离及 Tauri 本地 API 链路测试。

2026-11-05 已在 macOS、Trae 国际版 3.6.13 的真实 Free 账号上验证 SG 服务：成功读取 byteCrypto 登录封装、金额额度和官网历史用量；在隔离临时目录运行真实 Tauri sidecar，经本地 HTTP 接口完成额度查询、用量同步及汇总查询，第二次同步没有新增桶。实测确认用量接口需要采用每页 20 条（100 条请求返回 HTTP 400），已补回归断言。验证未改写 Trae 文件，未上传账号用量，也未将真实登录记录或原始会话数据加入仓库。

**Windows/Linux、US 服务、非零缓存写入及原生 GUI 展示仍未实机验证；输入与缓存的口径仍需与官网展示进一步对照。** 本方案使用内部接口，Trae 升级后字段及认证方式可能变化。
