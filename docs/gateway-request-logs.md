# 网关请求日志

Tauri 网关保留两种独立的本地记录：

- `~/.ai-usage/agent-router/history/YYYY-MM-DD.json`：原有请求摘要，保留 7 天，每日最多 1000 条。不包含正文。
- `~/.ai-usage/agent-router/request-archive/YYYY-MM-DD/<request-id>.json`：从此次更新启用起保存详细请求，不补录过去的正文。数据目录被覆盖时，路径跟随应用数据目录。

在 AI 网关右上角点击「请求日志」，可查看列表、按模型/协议/HTTP 状态码/日期/请求 ID 筛选已加载的记录、加载更早记录，打开详情或导出 JSON。详情 API 只在原有 host-key 保护的管理端开放，不对下游模型客户端开放。

每条详细记录包含客户端请求的方法、路径、安全请求头和 JSON 正文（提示词、历史消息、工具定义、工具参数、采样配置等），协议转换后传给渠道适配器的各次请求，以及上游返回的 JSON/SSE、错误正文、供应商请求 ID 和客户端最终收到的 JSON/SSE。还包括原有路由、状态、耗时、排队和重试信息。

`upstream.layer = provider-adapter` 表示记录边界在通用协议转换与渠道适配器之间。订阅渠道内部可能再次包装为供应商私有格式，或在插件内部续期/重试，这些内部 HTTP 细节不属于此归档边界。网关托管搜索通过普通 transport 发出的额外模型调用也在同一个请求上下文内归档。

正文仅保存本机，不加入统计上传/同步。认证、Cookie 等头脱敏，正文中的凭据字段和常见密钥字符串脱敏；已解析的上游 API Key 也会从正文中替换。普通提示词、代码及工具结果会被保留，便于排障。

默认容量为 1 GiB，超出后按文件写入时间清理最早的记录，保留当前记录。单个正文最多 8 MiB，单次请求所有正文共享 16 MiB，每条最多保留 16 次上游调用。超限会明确标记 `truncated` / `upstreamOmitted`，取消或中断标记 `incomplete`，不会伪装成完整内容。流按原有消费速度捕获，不提前读取成功响应，不阻塞等待日志落盘。

文件权限为 0600，目录为 0700，写入先临时文件再重命名。最多等待写入 8 条详细记录；磁盘失败或队列满会在管理端状态中报告，队列丢弃数量保存在本次进程的 `archive.dropped`。日志故障不影响模型请求。未通过网关鉴权、非模型路由和 HTTP 解析前被拒绝的流量不归入模型请求详情。

响应头 `x-agent-router-request-id` 与详情文件名、摘要 ID 一致；正常响应和网关生成的模型错误响应均可用于关联。
