修复 Hermes Agent 的用量被记到「会话开始那一天」的问题：Hermes 的 Telegram / Webhook 等消息会话不会结束，只要在同一个会话里继续用，此后每天新产生的 Token 都会被算到会话开始的那天 —— 面板和线上表现为「最近几天没有用量」，而很久以前的那一天被越撑越大。现在按会话最后一次活动的时间统计，新产生的用量会落在实际发生的当天。CLI 与 Desktop 面板同步生效（同一份 core 解析器）。

影响范围与口径说明：

- **只影响此后新产生的用量**：已经写入本地记录的旧数据不会被重排，也不会自动修正旧日期 —— 升级时不会重算历史，避免重复计数。
- **日常同步不改变总量**：每分钟的增量同步仍按「当前累计值 − 上次快照」统计，不重复计数、不丢量，只是归集的日期变正确。
- **重新全量解析（新装，或在面板把统计范围从 7 天放宽到 90 天）时分布会变化**：长会话的历史累计量会从「会话开始那天」移到「它最后一次活动那天」，因此各天的数字会重新分布。由于统计口径是最近 90 天，窗口内的总量可能小幅增减：真实活动日早于窗口起点的用量不再计入，而此前因归集日期落在窗口外而被丢弃的用量会重新计入。
